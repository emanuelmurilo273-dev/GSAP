# Prévias públicas (SiteHunter AI)

Páginas estáticas geradas pelo app a partir de dados públicos das empresas, para demonstração.
São prévias não publicadas pelas empresas: objetos 3D e várias fotos são ilustrativos e identificados no rodapé de cada página.
Recursos em `_assets/`: three.js (MIT), modelos 3D do Poly Haven (CC0) e fotos de pratos em domínio público (ver `_assets/models/LICENSES.md`).
